# Game Polish

Read `docs/game/ART_DIRECTION.md` and confirm the underlying mechanic already works before polishing it.

Favor small, high-impact feedback: crack cues, target wobble, fragments, detach motion, bubbles, turtle relief, restrained score text, ambience, and the final rescue sequence. Keep effects interruptible, performant, and subordinate to input clarity. Do not add large animation/audio systems to conceal broken mechanics.

Verify that effects do not double-fire, block input, leak across restarts, or undermine reduced-motion/audio controls where present. User instructions override this workflow.
